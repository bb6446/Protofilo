# MD Biplob // 3D Interactive WebGL Portfolio & Apparel Design Studio

High-impact 3D Interactive WebGL Portfolio, T-Shirt Apparel Case Studies Showcase, and Firebase CRM Admin Hub for MD Biplob (Senior Graphic & Apparel Designer).

## ✨ Features
- 🌌 **Three.js 3D WebGL Engine**: Interactive particle galaxy, core geometry decals, and GSAP scroll choreography.
- 🎨 **10 Live Portfolio Case Studies**: High-resolution zoom inspection, vector separations, tech packs, and streetwear typography.
- 🛡️ **Admin Control Hub & CRM**: Google Sign-In (`talukderbiplob498@gmail.com`), project management, skill proficiencies, inquiry message manager, and 1-click JSON backup.
- 🚀 **Netlify & GitHub Actions**: Automatic CI/CD with SPA routing fix (`public/_redirects`).

## 🛠️ Tech Stack
- **Frontend**: Vanilla JavaScript (ES Modules), HTML5, Modern CSS Design System, Three.js, GSAP, Lucide Icons
- **Backend & Database**: Firebase Firestore REST API + Persistent LocalStorage Fallback
- **Hosting**: Netlify & GitHub Pages
